# 自作PC・コンピュータ 学習アプリ

自作PCの知識を、クイズ・表の暗記・価格の比較で学ぶためのWebアプリです。
ビルド不要の素のHTML/CSS/JavaScriptで動きます。

- **クイズ** … 367問（基礎92／標準177／応用98）。4択・一問一答・苦手復習・中断再開
- **表を覚える** … 41表686マスを、穴埋めと全消し暗唱で暗記
- **パーツ価格** … 価格帯の比較グラフ、構成見積もり（互換性チェック・電源容量計算）、相場の推移

## 誌面画像について

このリポジトリには、出典元である雑誌**『自作PC完全マスター2026』の誌面画像は含まれていません**（著作物のため）。
アプリ内の「誌面を見る」ボタンは、画像がある環境でのみ表示されます。

問題文・解説・表のデータは、誌面に書かれている**事実（型番・仕様・数値）を自分の言葉でまとめ直したもの**です。
学習の際は、出典元の誌面とあわせてご確認ください。

## 使い方（ローカル）

`index.html` をブラウザで開くだけです。サーバーは不要で、成績や記録はブラウザ内に保存されます。

### 誌面画像を自分の手元だけで使いたい場合

`img/pages/` に `p012.jpg` 〜 `p111.jpg` の形式で画像を置くと、「誌面を見る」ボタンが自動的に現れます。
`img/` は `.gitignore` で除外してあるので、**push しても公開されません**。

## 価格フィード（毎日自動取得）

GitHub Actions が毎朝6時（日本時間）に Yahoo!ショッピングの商品検索APIを叩き、
主要パーツ49点の価格を `data/prices.js` に追記します。自分のPCが起動していなくても更新されます。

```
.github/workflows/update-prices.yml   毎日実行するワークフロー
tools/fetch_prices.py                 取得スクリプト
tools/parts.json                      取得対象49点
data/prices.js                        生成物（アプリが読み込む）
```

### セットアップ

#### 1. Yahoo!のアプリケーションID（Client ID）を取る — 無料

1. [Yahoo!ショッピング用アプリケーションの登録ページ](https://e.developer.yahoo.co.jp/shopping/register) を開く
2. Yahoo! JAPAN ID でログインし、フォームに入力して登録する
   - アプリケーション名：何でも構いません
   - 種類：サーバーサイド（Webアプリケーション）
   - サイトURL／コールバックURL：GitHub PagesのURL、または `http://localhost/`
3. 発行された **Client ID** をコピーする

> 「ストア運営サポートAPI」は**別のAPI**で、審査に1〜2週間かかります。
> 今回使うのは**商品検索API**なので、必ず上のリンクから登録してください。

#### 2. リポジトリに push する

**Public** リポジトリを作り、このフォルダの中身を push します。
`.gitignore` により `img/` と `.env` は自動的に除外されます。

#### 3. Client ID を Secrets に登録する

**Settings → Secrets and variables → Actions → New repository secret**

| Name | Secret |
|---|---|
| `YAHOO_APPID` | 手順1でコピーした Client ID |

#### 4. GitHub Pages を有効にする

**Settings → Pages** → Source: `Deploy from a branch` / Branch: `main` / フォルダ: `/ (root)`

数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開されます。

#### 5. 動かす

**Actions タブ → 「価格を毎日取得する」→ Run workflow** で手動実行。1〜2分で `data/prices.js` が更新されます。
アプリは同じリポジトリの `data/prices.js` を自動で読むので、URLの設定は不要です。

## Client ID（APIキー）の扱い方

**リポジトリの中のファイルには絶対に書かないこと。**
一度でも公開リポジトリに commit すると、あとで消しても Git の履歴・フォーク・各種キャッシュに残り続けます。

| 用途 | 置き場所 |
|---|---|
| GitHub Actions（本番） | リポジトリの **Secrets**（暗号化。ログにも出ない） |
| 手元で試すとき | `tools/.env`（`.gitignore` 済み） |

`tools/.env.example` をコピーして `tools/.env` を作り、値を書き換えてください。
読み込み順は「環境変数 → `.env`」なので、Actions 上では Secrets が優先されます。

PowerShell で一時的に渡すこともできます。

```powershell
$env:YAHOO_APPID = "取得したClient ID"
python tools/fetch_prices.py
```

**漏らしてしまったら**、commit を取り消すだけでは不十分です。
[アプリケーションの管理ページ](https://e.developer.yahoo.co.jp/dashboard/) でそのアプリを削除して発行し直し、Secrets を差し替えてください。

## 仕様と注意点

- **取得元**：Yahoo!ショッピング商品検索API v3。ツクモ、ソフマップ、ark などPC専門店のYahoo!店が含まれます
- **各日の値**：検索結果のうち誌面価格の 0.4〜2.5 倍に収まる商品の**最安値と中央値**。送料・ポイントは含みません
- **アクセス間隔**：Yahoo!の制限「1クエリ/秒」に対し1.1秒あけています。**詰めないでください**
- **履歴の間引き**：直近60日は毎日、それ以前は週1点（最大250点）。2年運用で約350KB
- **クレジット表示**：Yahoo!デベロッパーネットワークの規約により「Webサービス by Yahoo! JAPAN」の表示が必要です。
  ページ下部に入れてあります。**消さないでください**
- **cron の停止**：60日間リポジトリに更新がないと GitHub が自動実行を止めます。たまに手動実行してください
